## Proyectos destacados

### Sistema de gestión de cobros y gastos · *en producción*

[▶ Demo en video](https://youtu.be/8ZTCAMH56X0) · [Repositorio](https://github.com/facuartola/sistema-gestion-cobros)

Aplicación de administración para una consultora de coaching deportivo: cuotas de clientes, gastos por categoría, certificación por módulos, recordatorios, exportación a CSV y copias de seguridad.

- Modelo relacional en **PostgreSQL** con migraciones versionadas y **Row Level Security** en todas las tablas.
- **Backend en Node.js**: API REST propia (rutas de API de Next.js) que valida la sesión antes de leer o escribir, y una función serverless programada en Netlify.
- **+500 tests** con Vitest sobre la lógica de negocio.
- Deploy en Netlify con una función programada de mantenimiento.

`JavaScript` `React` `Next.js` `Node.js` `PostgreSQL` `Supabase` `Vitest`

- Defino el modelo de datos y las reglas de negocio antes de escribir la interfaz.
- Escribo tests para la lógica crítica (montos, fechas, estados de pago).

- Documento las decisiones técnicas y cómo correr cada proyecto.
